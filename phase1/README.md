# Phase 1 - TF-IDF Resume Screening

This phase implements a TF-IDF-based baseline for resume-job matching.

## Pipeline

Resume + Job Description
→ Text Preprocessing
→ TF-IDF
→ Cosine Similarity
→ Candidate Matching
→ Ranking
→ Evaluation

## Dataset

The experiments use a public Resume-Job Fit dataset containing 2,385 resume-job pairs.

## Status

Phase 1 baseline implementation completed.

Future work includes semantic matching using Sentence-BERT, fairness-aware evaluation and mitigation, explainability, and web application development.
